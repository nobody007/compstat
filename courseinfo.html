Computational Statistics 

Course Information

https://nobody007.github.io/compstat

A comprehensive introduction to statistical computations including Numerical Optimization, EM algorithm, Numerical Integration, Simulation and Bootstrapping.

Textbooks

Prerequisite

  • Basic knowledge of statistics and programming skill. Knowledge of statistical programming language R and/or python is recommended.

    • Homework (70%) : There will be 10 homeworks.

     

    Computer work

    The computer is an essential instrument in the course. I assume you have basic computer knowledge and very basic computer programming skill. R and/or python is an excellent programming tool for the computations.
